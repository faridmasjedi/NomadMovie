# Website

The guide at <https://faridmasjedi.github.io/NomadMovie/>: one page (`index.html`) with a tab per feature, plus
`assets/` (style, script, icon) and `data/catalog.json` (the effect and transition lists).

It's published by the **Website** workflow at the end of every release (see [RELEASING.md](../RELEASING.md)).
The demo GIFs (`media/`) and catalog animations (`catalog/`) live only on the `gh-pages` branch, so a local copy
of this folder shows empty frames where the demos go.
